# Arhbo 钢琴谱

根据哔哩哔哩 UP 主 **LeYangMusic** 视频中展示的钢琴谱图，重新录入、逐页校对并合并的可编辑乐谱。全曲 112 小节，采用钢琴双谱表，谱面为 B 大调五升号、4/4 拍，速度为四分音符 = 118。

## 来源

- 扒谱及视频展示：**LeYangMusic**
- 原视频：[arhbo 卡塔尔世界杯主题曲 越听越上头 扒了个谱](https://www.bilibili.com/video/BV1a841177KQ/)
- 本仓库文件根据视频中的谱图独立录入。原曲和原扒谱的权利归各自权利人。

## 文件

| 文件 | 用途 |
| --- | --- |
| [arhbo.musicxml](arhbo.musicxml) | 可编辑的钢琴双谱表。用 MuseScore 打开，右手为高音谱号，左手为低音谱号。 |
| [arhbo.mid](arhbo.mid) | 钢琴播放与 DAW 导入。左右手分轨，时长约 3 分 48 秒。 |

## 校对说明

- 全曲覆盖七页谱图的第 1–112 小节，保留原谱换页位置。
- 第 43、47 小节按原图分写八分休止符和十六分休止符。
- 第 78–81 小节按谱区分八分三连音和普通八分音符，跨页渐强连续。
- MusicXML 与 MIDI 的音高和起止位置已逐音比对。MIDI 已进行全曲离线播放验证。
- MIDI 中的具体力度数值、倚音时长及部分踏板释放时点是播放实现值。
